# 1. ABSTRACT

The Smart Home Occupancy & HVAC Control Simulator is a Linux-based smart-home simulation project developed using C++ and a Linux character device driver written in C.

The system simulates sensor data such as occupancy, temperature, humidity, and Air Quality Index (AQI). The Linux character device driver generates dynamic sensor values and makes them available through the `/dev/smart_sensor` device file.

The C++ application reads and processes these values to make automatic HVAC decisions. Depending on occupancy and temperature, the system can activate cooling, heating, or turn the HVAC system off. Fan speed is also determined according to temperature.

The system additionally monitors humidity and air quality, calculates estimated energy consumption, provides energy-saving recommendations, performs continuous monitoring, and stores sensor readings in a CSV file.

The project demonstrates the integration of Linux kernel programming, character device drivers, C/C++ programming, file handling, sensor simulation, HVAC control logic, and energy management.

# 2. INTRODUCTION

Smart home systems use sensors and automated control mechanisms to improve comfort, energy efficiency, and environmental monitoring.

This project simulates a smart home environment in which sensor data is generated by a Linux character device driver. The user-space C++ application communicates with the driver through the `/dev/smart_sensor` device file.

The application continuously processes sensor readings and determines the appropriate HVAC operation.

The major parameters monitored by the system are:

- Occupancy
- Temperature
- Humidity
- Air Quality Index (AQI)
- Energy consumption

The project also maintains a CSV log of sensor readings and calculates energy statistics from the stored data.
